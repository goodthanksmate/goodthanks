# goodthanks

Personal site at goodthanks.org. GitHub Pages builds it automatically with Jekyll, so there's no build step.

## Writing posts

Use [Pages CMS](https://app.pagescms.org): sign in with GitHub, open this repo, and go to **Blog posts → Add**. Hitting save commits the post and the site updates in about a minute.

- **Blog posts** go in `_posts/`
- **Tabs** in `_tabs/` are extra pages that show up in the top menu. `order` sets their position.
- **Home page** is `index.md`, the intro text on the landing page
- **Images** you upload in the editor go into `assets/images/`
